=====================================================================
URUTAN RILIS
=====================================================================
1. Di komputer ber-Java 11+:  npm ci → npm run typecheck → npm test → npm run test:rules → npm run build
2. GitHub: upload ISI folder (bukan ZIP) ke branch "staging". Jangan ikutkan .env / file JSON service account.
3. Vercel Preview: isi env vars (Preview), aktifkan Protection Bypass for Automation, tunggu Ready.
4. Firebase staging: publish Rules (perintah di atas).
5. Panggil sync mode check-config → harus ok: true. Lalu mode dry-run.
6. GoAkal: arahkan URL webhook ke Preview (jam sepi).
7. Jalankan docs/STAGING-GOAKAL-CHECKLIST.md (10 skenario).
8. Kembalikan URL webhook ke produksi.
9. Production: isi env vars Production → merge staging ke main → tunggu Ready → publish Rules produksi.
10. check-config & dry-run di produksi → 1 transaksi produksi uji → sync terjadwal (mis. tiap 1 jam).
