KEPUTUSAN UTAMA
Fokus: pemula yang sudah punya satu skill menyiapkan bantuan kecil untuk bisnis yang sudah berjalan, mencoba pendekatan personal, lalu mengevaluasi dan memperbaiki. Ini hipotesis yang akan diuji, bukan pembeda yang sudah terbukti atau jaminan pelanggan.

PERUBAHAN APLIKASI
- Misi Pertama: sembilan tahap dengan hasil kerja, contoh ilustrasi, kriteria cek mandiri, bantuan saat buntu, dan materi/alat sesuai kebutuhan.
- Simpan draf sebagian tanpa wajib profil lengkap. Unduh teks hasil yang sudah tersimpan.
- Checklist dan catatan tujuh hari lama tetap di /app/action-plan/arsip; tidak dimigrasikan menjadi bukti hasil kerja baru.
- Dashboard dan navigasi mendahulukan Misi. Assessment, Passport dan Dream Pact opsional; skor profil diberi batas dan disembunyikan dalam detail opsional.
- Landing/paket diselaraskan. Pendampingan Impact hanya pencatatan minat, bukan penjualan dengan jadwal pasti. Paket/trial aplikasi tidak menjanjikan konsultasi harian.
- Tautan AI Coach Heybinder dari Bos di Akun & Paket. Layanan eksternal, percakapan belum sinkron ke Misi. Ikuti ketentuan layanan dan periksa jawabannya.
- Visual Founder Studio dipertahankan: lime/lilac/sky/pink, garis dan bayangan tegas, area baca putih, navigasi HP serta kembali ke Dashboard.

UPLOAD GITHUB → CEK VERCEL
1. Ekstrak ZIP dari Downloads, buka folder genz-preneur-os di dalamnya.
2. Buka repo GitHub yang terhubung proyek Vercel Bos (repo sebelumnya: sudenb31/genzpreneur). Pastikan repo dan branch deployment benar.
3. Add file → Upload files. Upload seluruh ISI folder proyek ke root repo. Jangan upload ZIP atau menambah folder pembungkus genz-preneur-os di dalam repo.
4. Pastikan src/content/mission.ts, src/lib/mission.ts, src/pages/MissionPage.tsx serta perubahan src/main.tsx ikut terunggah, juga docs, tests, public dan konfigurasi.
5. Commit changes, misalnya: Sambungkan Misi Pertama dan selaraskan janji produk.
6. Vercel → proyek Bos → Deployments. Tunggu deployment commit tersebut berstatus Ready. Buka URL deployment itu dan uji; jangan menganggap build lokal berarti production sudah terpasang.
7. Jika produksi belum berganti, periksa branch/domain yang aktif, lalu hard refresh Ctrl+Shift+R atau buka tab baru di HP.
8. Tidak perlu mengubah environment variables untuk revisi ini. Jangan menimpa konfigurasi Firebase produksi dengan nilai contoh .env.example.

BATAS FUNGSIONAL
- Centang kriteria adalah penilaian peserta, bukan pemeriksaan otomatis atas kualitas atau keberhasilan bisnis.
- Draf belum disimpan masih berada di layar saja. Dialog melindungi pindah lewat tombol tahap dan tautan aplikasi, dan browser memberi peringatan saat menutup/memuat ulang. Tombol Back/Forward browser pada navigasi SPA belum mempunyai dialog khusus: simpan dahulu. Ini bukan autosave/offline draft.
- Teks maksimal 1.600 karakter per tahap, dengan batas serialisasi 2.000 karakter; teks penuh karakter yang perlu escape (misalnya banyak baris baru) bisa perlu diringkas. Penyimpanan gagal tidak memotong teks diam-diam.
- File contoh disimpan sendiri; Misi hanya menyimpan teks/tautan. Alat belum otomatis menyalin hasil ke Misi. Gunakan kode prospek, bukan nomor/email pelanggan.
- Sesuai Rules saat ini, pemilik dan admin bisa membaca progres. Item Tersimpan memiliki aturan terpisah hanya untuk pemilik.

CEK SETELAH DEPLOY DENGAN AKUN PESERTA UJI
1. Masuk → Dashboard → Lanjut Misi Pertama. Profil kosong tidak menjadi prasyarat.
2. Isi draf tahap pertama, simpan tanpa semua centang. Buka halaman lain, kembali dan refresh: teks tetap ada. Jika gagal, catat error; jangan ubah Rules sembarang.
3. Ubah teks lalu pilih tahap lain: dialog tampil; Kembali ke draf mempertahankan teks. Simpan sebelum memakai Back/Forward browser.
4. Centang kriteria, simpan; ubah teks: centang kembali kosong agar dinilai lagi.
5. Isi tahap lain; unduh hasil tersimpan dan periksa file teks. Pastikan catatan tujuh hari lama dan progres pelajaran tetap ada.
6. Uji peserta Spark dalam mode Sesuai paket: kerangka Misi tersedia, alat tambahan tetap terkunci sesuai akses.
7. Akun & Paket → Buka undangan AI Coach. Uji dengan akun peserta baru dan ikuti instruksi Heybinder tanpa mengirim data pelanggan.
8. HP: menu bawah Beranda/Misi/Alat/Akun, tombol Menu untuk semua fitur, kembali ke Dashboard bekerja.
9. Landing: harga aplikasi Spark/Boost, Impact hanya daftar minat, tidak ada klaim konsultasi harian atau jaminan hasil.
