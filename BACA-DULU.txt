CARA MEMASANG — UPLOAD GITHUB
1. Buka folder Downloads, cari genz-preneur-os-design-revisi-2026-10-17.zip.
2. Klik kanan file ZIP, pilih Extract All / Ekstrak Semua.
3. Buka folder hasil ekstrak, lalu buka folder genz-preneur-os di dalamnya.
4. Buka https://github.com/sudenb31/genzpreneur. Pastikan branch yang dipakai adalah branch yang terhubung ke deployment Vercel Bos.
5. Klik Add file, lalu Upload files.
6. Upload seluruh ISI folder genz-preneur-os ke root repo: folder src, public, docs, tests, dan file konfigurasi lainnya. Jangan upload file ZIP atau folder pembungkus genz-preneur-os sebagai folder baru di dalam repo.
7. Tulis commit message: Revisi desain, navigasi HP, dan dashboard tindakan.
8. Klik Commit changes untuk menyimpan ke branch deployment Bos.
9. Buka Vercel, pilih proyek GenZ Preneur, masuk Deployments. Tunggu deployment terbaru berstatus Ready.
10. Buka situs. Jika masih terlihat versi lama, tekan Ctrl+Shift+R di komputer, atau buka tab baru/incognito di HP dan masuk kembali.
