GENZ PRENEUR — INTEGRASI GOAKAL & EMAIL VOUCHER
Revisi 19 Oktober 2026

STATUS
Kode integrasi sudah dibuat dan lulus tes lokal yang tersedia. Belum diunggah ke GitHub, belum dideploy ke Vercel, belum menerima secret produksi, dan tidak menyentuh transaksi/data produksi.

ALUR BARU
1. Webhook GoAkal mengirim transaksi PAID ke /api/goakal/webhook.
2. Server memverifikasi token dan memetakan ID price scheme ke spark/boost/impact.
3. Firestore transaction membuat tepat satu order internal dan satu voucher unik per paymentId.
4. Voucher maxUses 1, kedaluwarsa default 30 hari, dan terikat ke email pembeli.
5. Resend mengirim kode serta link aktivasi otomatis ke pembeli.
6. /api/goakal/sync memakai External API key untuk mengambil ulang transaksi PAID yang mungkin terlewat.

YANG DIPERLUKAN SEBELUM BISA AKTIF
- API key GoAkal scope external_api.
- Verification token webhook GoAkal.
- Service cuid dan price scheme cuid untuk setiap paket.
- Firebase service-account JSON.
- Akun/API key Resend dan domain email pengirim yang sudah diverifikasi.
- Secret acak untuk kode voucher dan endpoint sinkronisasi.

JANGAN KIRIM SECRET KE CHAT ATAU COMMIT KE GITHUB.
Masukkan semuanya sebagai Environment Variables di Vercel. Contoh nama dan format ada di .env.example dan docs/GOAKAL-INTEGRATION.md.

URUTAN RILIS YANG DISARANKAN
1. Baca docs/GOAKAL-INTEGRATION.md.
2. Di mesin dengan Java: npm ci, npm run typecheck, npm test, npm run test:rules, npm run build.
3. Upload isi folder proyek ke branch staging GitHub.
4. Di Vercel Preview, isi semua environment variables server. Jangan beri prefix VITE_ pada secret.
5. Publish Firestore Rules ke proyek staging.
6. Deploy Preview sampai status Ready.
7. Set webhook GoAkal staging ke https://URL-PREVIEW/api/goakal/webhook.
8. Bayar satu transaksi uji. Pastikan hanya satu order, satu voucher, satu email.
9. Kirim ulang event/sync. Pastikan tidak ada voucher atau email kedua.
10. Pastikan akun dengan email lain ditolak dan email pembeli berhasil menukar voucher.
11. Setelah semua lolos, ulangi environment variables, Rules, dan deployment pada Production.

CATATAN GITHUB → VERCEL
Upload source, bukan ZIP. Commit pada branch yang terhubung akan memicu Vercel. Tunggu deployment berstatus Ready lalu tes endpoint. Environment variables yang baru ditambahkan memerlukan deployment baru.

CATATAN GOAKAL
Webhook adalah jalur real-time. API key dipakai endpoint sync sebagai pemulihan. Gunakan price scheme cuid, bukan judul, karena judul bisa berubah.

BATASAN
- Email otomatis baru benar-benar berjalan setelah Resend dan domain sender siap.
- Sinkronisasi memindai maksimal 2.000 transaksi per service per eksekusi.
- Price scheme tanpa mapping tidak diberi voucher sampai konfigurasi diperbaiki dan event/sync diulang.
- Jangan menghapus koleksi goakalOrders karena itu menyimpan idempotensi dan status email.
- Tidak ada data produksi yang dimigrasikan oleh source ini.
