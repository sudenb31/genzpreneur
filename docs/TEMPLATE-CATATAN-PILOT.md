Template kosong untuk founder; bukan data peserta atau fitur analytics baru. Salin per peserta memakai P01–P06. Simpan daftar identitas terpisah dengan akses terbatas. Hapus contoh berisi data pribadi sebelum membahasnya.

## Persetujuan yang dicatat terpisah

Untuk tiap pilihan, catat ya/tidak, tanggal, versi penjelasan dan cara mencabut izin. Jangan gunakan centang default.

1. Ikut program dan memahami cakupan/batasnya: ______
2. Catatan/artefak anonim dipakai mengevaluasi pilot: ______
3. Contoh tertentu dibahas di sesi, audiens dijelaskan: ______
4. Sesi direkam serta tujuan/penyimpanannya dijelaskan: ______
5. Kutipan atau hasil dipublikasikan sebagai testimoni: ______ (minta persetujuan lagi atas versi final)

Menolak publikasi tidak mengurangi akses program. Izin peserta bukan izin menggunakan data pelanggan bisnis. Mintakan izin pemilik data secara terpisah bila diperlukan. Hindari merekam bila tidak diperlukan; sediakan alternatif pembahasan teks anonim.

## Rubrik peninjau (berbeda dari centang mandiri aplikasi)

Gunakan 0 = belum terlihat, 1 = perlu perbaikan, 2 = cukup jelas untuk dicoba. Catat alasan dan siapa peninjaunya. Bukan skor kesiapan usaha atau prediksi pendapatan. “Cukup” bila semua aspek minimal 2; pekerjaan perlu ditinjau ulang jika ada pelanggaran izin, informasi keliru atau janji tak sanggup dipenuhi.
